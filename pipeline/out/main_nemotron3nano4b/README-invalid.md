# Этот каталог непригоден для анализа

Прогон сделан старой сборкой инструмента на модели `nemotron_h`, у которой
`l_out` есть только на 17 из 42 слоёв. Инструмент требовал захвата всех
выбранных слоёв, поэтому **каждая** строка получила `status: skipped`,
`reason: "failed to capture hidden states"`, а массивы `hidden_a.npy` /
`hidden_c.npy` остались нулевыми (файлы заранее размечены под 6000 строк).

Что здесь есть и почему:

- `meta.jsonl` — 5269 строк, из них 3 битые (обрывы при перезапусках:
  строки 2631, 3956, 5269); 5266 корректных записей, все `skipped`.
  Поле `answer` содержит реально сгенерированный моделью текст, но
  `generated`/`pos_*`/`logprobs` старый код в skipped-строках обнулял.
- `hidden_a.npy`, `hidden_c.npy` — 1.5 ГБ каждый, все значения 0.
- `labels.csv` — честная разметка этих строк: все метки пустые (null),
  потому что `status != ok`.
- `main.log` — лог прогона.

Каталог оставлен как свидетельство ошибки. Для анализа используйте прогон,
сделанный после исправления (см. `pipeline/verify_run.py` и раздел в
`AGENTS.md`); полный прогон 6000 ещё не делался.
