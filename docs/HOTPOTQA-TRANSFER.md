# HotpotQA: перенос замороженной пробы Qwen3.5-0.8B

Протокол зафиксирован 2026-11-09 до генерации ответов. Разрешён только этот тест
Qwen3.5-0.8B Q4_K_M; другие модели и GAIA остаются отложенными.

## Неизменяемые элементы

- Источник: `pipeline/out/main_qwen08_q4/probe_model.npz`, **C / model layer 13,
  λ=1000**. SHA-256:
  `5e948cd2146d95fef7ad2b66b21c9c5d12fdd3cfc02c250f30fcb81a1ca7088c`.
- Признак: один 1024-мерный вектор C. В целевом массиве сохранён только слой 13,
  поэтому его array index равен **0**, а не 13.
- `w`, train `mu` и `sd` применяются без изменения. Нет обучения, выбора слоя,
  калибровки, смены направления score или подбора порога на HotpotQA.
- Ответ генерируется один раз. Отдельный проход состояний не является
  перепроверкой ответа моделью. Поиск, агентные инструменты и дополнительные
  модельные verification-проходы не используются.

Используется только dev/validation `distractor` из `hotpotqa/hotpot_qa`, ревизия

SHA-256 `c20b638ca82b21d04fe12e14ff417ad05153d4d215a65de54497fca4e972f7c6`.
Данные и диагностическая архивная копия хранятся на D:, не на C:.

Независимая проверка установила полное совпадение parquet и официального dev JSON
по всем полям всех 7405 строк, включая порядок документов и неизменённые строки

## Промпт и генерация

Пользовательское сообщение:

```text
Use the supplied paragraphs to answer the question.

Paragraphs:
[1] <original title>
<original sentence strings concatenated>

... every supplied paragraph in dataset order ...

Question: <original question>
Answer with just the answer, no explanation.
```

Штатный GGUF-шаблон вызывается с `enable_thinking=false`. На используемом runtime
он добавляет **пустой, уже закрытый** `<think>\n\n</think>\n\n` перед ответом;
reasoning-токены не генерируются. `add_bos=false`, первый токен 248045. Точка A —
последний токен всего этого отрендеренного промпта, C — последний содержательный
токен ответа без EOG. Определения точек и порядок проходов не изменены.

Флаги профиля `qwen-hotpotqa`: `--generate --max-new-tokens 64 --max-len 8192
--layers 13 -ngl 99`, `batch_rows=1`, штатный шаблон, raw argmax. `-b/-ub` не
передаются. Для каждого выбранного вопроса диагностирован полный промпт; все
оставляют 64 токена ответа в пределах `max_len`.

## Разметка и сравнение

- **Все 500 попыток:** официальный whole-answer EM и средний answer F1 HotpotQA.
  Обрыв не удаляет попытку из accuracy; оценивается весь фактический ответ.
  Отсутствующий/пустой ответ получает ноль. Нет substring matching или извлечения
  удобного final из развёрнутого ответа.
- EM использует официальную нормализацию регистра, ASCII-пунктуации, артиклей и
  пробелов. F1 повторяет специальное правило `yes`/`no`/`noanswer`.
- Источник evaluator: `hotpot_evaluate_v1.py` ревизии
  `fa3a36370899e1d85822de61e58c85ea19993154`, SHA-256
  `d35fc91a6db21d791dbdda11daf3856e9359f5701d54e3eefba20d88fecc02c0`.
  В пайплайне используются только правила answer EM/F1; supporting-facts и joint
  метрики не измеряются.
- **Primary cohort:** `status=ok`, сгенерированный завершённый непустой ответ,
  валидный C-вектор и конечные first-token scores. Одна общая маска применяется к
  пробе, logprob и отрицательной энтропии.
- Оценочные метки — `hotpot_em`; все строки помечены `test`. Это не замена
  тренировочной метки `correct_filtered_b` исходной пробы.
- Scores: сохранённый probe logit, `logprobs[0]`, `-entropies[0]`. Выше означает
  большую уверенность в правильности; направление не перевыбирается.
- AUROC/AUPRC и парные разности: percentile bootstrap 1000, seed 42,
  пересэмплирование одних и тех же вопросов для сравниваемых методов.
- Отдельно: completion/primary coverage и описательная accuracy при сохранении
  самых уверенных 50% primary-ответов. Число сохраняемых строк округляется вверх;
  ties разрешаются исходным порядком. Это заранее заданный бюджет, не оптимальный
  порог и не оценка откалиброванной вероятности. Brier/ECE здесь не вычисляются.

## Оговорка о runtime

Исходная проба получена на `3ad2230`, build 37; HotpotQA генерируется на
`785322d17`, build 12033. Контроль на прежних TriviaQA-вопросах имел 75.0% совпадений
ответов и 97.3% меток. Поэтому это **не побитово чистый dataset-only перенос**:
изменены датасет/контекст, правило оценки правильности и runtime. Сравнение трёх
методов внутри HotpotQA при этом выполняется на одинаковых строках одного прогона.

## Артефакты и порядок стадий

- `pipeline/data/hotpotqa_qwen08_v2/protocol.json`: ID, входы/эталоны, длины,
  model/probe/runtime/implementation fingerprints. SHA-256:
  `f0f1f88cfc277247d97c37f2acf8ec8c0728a7b85a9121e8c9fcbf5d830d0657`.
- `pipeline/data/hotpotqa_qwen08_v2/{pilot,main}.jsonl`: только генерационный вход;
  `*.questions.jsonl` — отдельные оригинальные вопросы и эталоны для разметки.
- `pipeline/out/pilot_qwen08_q4_hotpotqa_v2`: pilot 200, official labels, state
  verification и final class-balance gate.
- `pipeline/out/main_qwen08_q4_hotpotqa_v2`: evaluation 500, массивы `[500,1,1024]`,
  official labels, `verify.json`, `transfer.json`, `transfer_scores.csv`.

Стадии через `scripts/run.ps1`: `doctor -> inputs -> prompt -> pilot`, затем только
после passed gate, проверки состояний и просмотра ответов — `main -> label ->
verify -> transfer`. Для этого профиля `baseline/probe/probe2` запрещены, в том
числе при попытке опустить профиль или подставить другой профиль при анализе.

Каждый выход создаётся под новым именем/тегом. Старые source weights, прогоны и
неудачная пустая prepared-папка `v1` сохраняются. Повторная генерация не разрешена
самим наличием этого рецепта.

## Результат предварительного теста

Все 500 вопросов обработаны, 0 skipped, 0 empty, 1 truncated. Gate и full state
verify прошли без ошибок и предупреждений. Общая primary-выборка — 499 строк,
161 правильный ответ по official EM; completion/primary coverage 99.8%.

All-attempt EM: **32.2%** [28.4%,36.6%]; средний answer F1: **42.9%**
[39.0%,46.8%].

| score | AUROC [95% CI] | AUPRC [95% CI] | EM при сохранении top 250 |
|---|---:|---:|---:|
| frozen C/13 probe | 0.6441 [0.5939,0.6975] | 0.4451 [0.3775,0.5305] | 42.4% |
| first-token logprob | 0.6655 [0.6135,0.7115] | 0.4745 [0.4056,0.5571] | 43.6% |
| negative first-token entropy | 0.6879 [0.6351,0.7348] | 0.4889 [0.4171,0.5753] | 44.8% |

Probe − logprob: ΔAUROC −0.0214 [−0.0891,+0.0525], ΔAUPRC −0.0294
[−0.1152,+0.0627]. Probe − negative entropy: ΔAUROC −0.0438 [−0.1136,+0.0307],
ΔAUPRC −0.0438 [−0.1341,+0.0507]. Все парные интервалы включают ноль.

**Преимущество замороженной пробы над стандартной уверенностью не подтверждено.**
Сигнал выше случайного сохранился, но baseline point estimates лучше. Это не
доказательство отсутствия любого переноса или превосходства baseline во всей
популяции: 500 вопросов дают заметную неопределённость. Не проводился тест
верификации ответов агентом; другие модели и GAIA не запускались.

Полные числа: `pipeline/out/main_qwen08_q4_hotpotqa_v2/transfer.json` (SHA-256
`6b5bb46649d083d5aeb1c2f56b8a0c6b27cbd1e311646ab189ac821a9cda27cd`),
построчные результаты — `transfer_scores.csv` (500 строк, 499 общих confidence
scores). Source probe SHA-256 после scoring совпадает с исходной; target fitting
